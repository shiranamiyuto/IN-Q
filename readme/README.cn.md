# IN-Q V2

[日本語](../README.md) | [English](README.en.md) | [简体中文](README.cn.md)

这是一个专为《怪物猎人：世界 冰原》设计的任务重置辅助工具。

本仓库用于分发 IN-Q V2 以及接收问题反馈。不公开源代码和内部开发资料。

## 下载

最新版本可以从 [Releases](https://github.com/shiranamiyuto/IN-Q/releases) 下载。

## 反馈问题

请使用 [问题反馈表单](https://github.com/shiranamiyuto/IN-Q/issues/new?template=bug-report-cn.yml)。

在反馈前，请确认以下几点：

- 确认 [现有 Issue](https://github.com/shiranamiyuto/IN-Q/issues) 中是否已存在相同的内容
- 注明 IN-Q / MHW 的版本号
- 详细说明复现步骤、期望结果以及实际结果
- 确认日志中不包含个人信息或认证信息

Issue 和附件将在互联网上公开。请勿发布 Steam 认证信息、存档数据、包含 Windows 用户名的路径、IP 地址等内容。

关于诊断信息的处理，请参考 [PRIVACY.md](../PRIVACY.md)。

## 支持范围

目前实机验证的对象为单人游玩。不保证在多人联机时的运行效果。
