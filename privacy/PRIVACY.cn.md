# 诊断信息与隐私

[日本語](../PRIVACY.md) | [English](PRIVACY.en.md) | [简体中文](PRIVACY.cn.md)

## 基本方针

IN-Q V2 在用户明确执行错误报告之前，不会将诊断信息发送到外部。

发布到 GitHub Issue 的正文和附件将在互联网上公开。在发送前，请在 IN-Q 的确认界面和 GitHub 的发布界面中检查内容。

## 计划包含在公开诊断信息中的项目

- IN-Q 本体及插件的版本
- MHW 的版本或构建版本
- 发生时间附近的状态转换
- 任务 ID、地图区域、营地、参与人数
- 超时、异常、内部处理失败
- MOD 加载器的版本
- 已安装 MOD 的文件名列表（仅限用户明确选择的情况）

## 不收集和发送的项目

- Steam 认证信息
- 存档数据本体
- 聊天正文
- 包含 Windows 用户名的绝对路径
- IP 地址
- 密码、API 密钥、令牌
- 其他认证信息

## 发送方法

诊断信息将被格式化为用户在发送前可以确认的形式。由用户在 IN-Q 打开的 GitHub 发布界面中最终执行发送操作。开发者的 GitHub 认证信息不会嵌入到 IN-Q 中。
