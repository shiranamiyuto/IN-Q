# IN-Q V2

[日本語](../README.md) | [English](README.en.md) | [简体中文](README.zh.md)

这是一个专为《怪物猎人：世界 冰原》设计的任务重新开始辅助工具。

本仓库用于分发 IN-Q V2 以及接收问题反馈。不公开源代码和内部开发资料。

## 下载

最新版本可以从 [Releases](https://github.com/shiranamiyuto/IN-Q/releases) 下载。

## 报告问题

请使用 [问题反馈表单](https://github.com/shiranamiyuto/IN-Q/issues/new?template=bug-report-zh.yml)。

在反馈之前，请确认以下几点：

- 确认 [现有 Issue](https://github.com/shiranamiyuto/IN-Q/issues) 中是否有相同的内容
- 注明 IN-Q / MHW 的版本
- 写明复现步骤、期望的结果和实际的结果
- 确认日志中不包含个人信息或认证信息

Issue 和附件将在互联网上公开。请不要提交 Steam 认证信息、存档数据、包含 Windows 用户名的路径、IP 地址等内容。

有关诊断信息的处理方式，请参阅 [PRIVACY.md](../privacy/PRIVACY.zh.md)。

## 支持范围

目前实机验证的对象为单人游戏。不保证在多人游戏中的运行效果。
