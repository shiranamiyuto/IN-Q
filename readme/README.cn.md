# IN-Q V2

[日本語](../README.md) | [English](README.en.md) | [简体中文](README.cn.md)

这是一个专为《怪物猎人：世界 冰原》设计的任务重置辅助工具。

本仓库用于分发 IN-Q V2 以及接收问题反馈。源代码和内部开发资料不予公开。

## 下载

最新版本可以从 [Releases](https://github.com/shiranamiyuto/IN-Q/releases) 下载。

## 报告问题

请使用 [问题反馈表单](https://github.com/shiranamiyuto/IN-Q/issues/new?template=bug-report-cn.yml)。

在反馈之前，请确认以下几点：

- 确认 [现有 Issue](https://github.com/shiranamiyuto/IN-Q/issues) 中没有相同的内容
- 注明 IN-Q / MHW 的版本号
- 详细说明复现步骤、期望结果以及实际结果
- 确认日志中不包含个人信息或身份验证信息

Issue和附件将在互联网上公开。请勿发布 Steam 身份验证信息、存档数据、包含 Windows 用户名的路径、IP 地址等。

有关诊断信息处理的说明，请参考 [PRIVACY.md](../privacy/PRIVACY.cn.md)。

## 支持范围

目前实机验证的对象仅限单人游玩。不保证在多人联机时的运行效果。
