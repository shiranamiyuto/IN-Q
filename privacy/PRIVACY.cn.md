# 诊断信息与隐私

[日本語](../PRIVACY.md) | [English](PRIVACY.en.md) | [简体中文](PRIVACY.cn.md)

## 基本方针

IN-Q V2在用户明确执行错误报告操作之前，不会向外部发送诊断信息。

提交至 GitHub Issue 的正文和附件将在互联网上公开。发送前，请在 IN-Q 的确认界面和 GitHub 的发布界面中核对内容。

## 计划包含在公开诊断信息中的项目

- IN-Q 本体与插件的版本
- MHW 的版本或构建版本
- 发生时间附近的状态转换
- 任务 ID、阶段、营地、参与人数
- 超时、异常、内部处理失败
- MOD 加载器的版本
- 已安装 MOD 的文件名列表（仅限用户明确选择的情况下）

## 不收集与发送的项目

- Steam 凭据
- 存档数据本身
- 聊天正文
- 包含 Windows 用户名的绝对路径
- IP 地址
- 密码、API 密钥、令牌
- 其他凭据

## 发送方法

诊断信息将被格式化为供用户在发送前确认的形式。由用户在 IN-Q 打开的 GitHub 发布界面中最终执行发送操作。开发者的 GitHub 凭据不会被嵌入到 IN-Q 中。
